# Snappy

Application de chat en Python, pensée pour une messagerie rapide et légère.

## Stack
- Python (backend + logique métier)
- Modèles de données dans `models.py`, persistance dans `database.py`

## Statut
Projet actif, en développement.

## Lancer le projet
```bash
pip install -r requirements.txt
python main.py
```
